Problem Statement:

Ayaan works as a logistics coordinator in a shipping warehouse. Each incoming shipment is 
tagged with a unique numerical code representing its priority. These codes arrive in a random 
order and are stored in a list.

To streamline processing, Ayaan wants to sort the list of shipment codes in ascending order 
using the Insertion Sort algorithm. This helps ensure that higher-priority shipments (lower 
code values) are processed first.

Your task is to help Ayaan write a program that takes a list of shipment codes (as integers in 
an array), sorts them using insertion sort, and prints the sorted array.


Example 1

Input:

4

4 2 1 3

Output: 

1 2 3 4 



Example 2

Input:

5

-1 5 3 4 0

Output: 

-1 0 3 4 5 

Input format :
The first line contains an integer n, representing the number of shipment codes.

The second line contains n space-separated integers representing the shipment codes.

Output format :
The output prints the sorted shipment codes (array) in ascending order in a single line, 
separated by spaces.
