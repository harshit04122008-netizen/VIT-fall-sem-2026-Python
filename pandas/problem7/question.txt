Problem Statement

Olivia, a teacher, wants to analyze student performance based on their test scores by categorizing 
them into predefined levels: Failing (0–49), Average (50–69), Good (70–89), and Excellent (90–100).

Write a program using the pandas library to classify student scores into these categories and compute 
the frequency of scores in each category. Display the results in a structured frequency distribution 
table using a pandas DataFrame.

Input format :
The input consists of a single line containing space-separated integers representing student scores.

Output format :
The first line prints "Student Performance Distribution"

The following lines print a frequency distribution table as a pandas DataFrame without row indices.
The table has two columns:

Performance Level — containing these exact categories (in this order):

Failing (0-49)
Average (50-69)
Good (70-89)
Excellent (90-100)
Frequency — the count of scores falling into each respective category.

The DataFrame should be printed exactly as shown, including column headers and spacing, with no 
index numbers.
