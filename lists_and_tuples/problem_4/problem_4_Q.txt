Problem Statement

George is working on a complex project where he needs to manage large datasets. Given a 
large list of integers, George wants to extract a specific segment of the list, reverse it, 
and then calculate the maximum and minimum values of the segment. 

Help George by writing a program to perform these tasks using negative slicing.

Input format :

The first line of input consists of an integer n, representing the number of elements in
 the list.

The second line consists of n space-separated integers representing the elements of the 
list.

The third line consists of an integer k, representing the start index (1-based) of the 
segment.

The fourth line consists of an integer m, representing the end index (1-based) of the 
segment.

Output format :

The first line of output displays the revered segment separated by space after reversing it.

The second line of output displays "Max: " followed by the maximum value in the segment.

The third line of output displays "Min: " followed by the minimum value in the segment.
